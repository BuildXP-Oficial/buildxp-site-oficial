01
O que é Docker?
Docker empacota sua aplicação e todas as suas dependências dentro de um container — um ambiente isolado e portável. Não importa se o servidor é Linux, Windows ou Mac: o container roda igual em qualquer lugar.
💡 Pense num container como uma "caixa" com tudo que sua app precisa para rodar, incluindo o sistema operacional mínimo.
02
Instalar o Docker
Baixe o Docker Desktop — ele inclui tudo que você precisa: engine, CLI e interface gráfica.
# Windows / macOS → https://www.docker.com/products/docker-desktop # Linux (Ubuntu) sudo apt update sudo apt install docker.io sudo systemctl start docker sudo systemctl enable docker # Verificar instalação docker --version
03
Imagens vs Containers
Uma imagem é o modelo/template — como uma classe em POO. Um container é uma instância rodando dessa imagem. Você pode ter vários containers rodando da mesma imagem.
ℹ️ Imagem = receita. Container = o prato pronto.
# Baixar uma imagem do Docker Hub docker pull nginx # Listar imagens baixadas docker images
04
Rodar seu primeiro container
O comando docker run baixa a imagem (se necessário) e inicia o container.
# Hello World do Docker docker run hello-world # Rodar nginx em background na porta 8080 docker run -d -p 8080:80 --name meu-nginx nginx # Acessar: http://localhost:8080
💡 -d = detached (background) | -p host:container = mapeamento de porta
05
Criar seu próprio Dockerfile
O Dockerfile é o "script de receita" que define como sua imagem é construída.
# Dockerfile — exemplo Node.js FROM node:20-alpine WORKDIR /app COPY package*.json ./ RUN npm install COPY . . EXPOSE 3000 CMD ["node", "index.js"]
# Buildar a imagem docker build -t minha-app . # Rodar a imagem buildada docker run -d -p 3000:3000 minha-app
06
Gerenciar containers
Comandos do dia a dia para controlar seus containers em execução.
docker ps # containers rodando docker ps -a # todos os containers docker stop meu-nginx # parar container docker start meu-nginx # iniciar container parado docker rm meu-nginx # remover container docker logs meu-nginx # ver logs
07
Docker Compose — múltiplos containers
O Compose permite orquestrar vários containers com um único arquivo. Perfeito para app + banco de dados + cache juntos.
# docker-compose.yml version: '3.8' services: app: build: . ports: - "3000:3000" depends_on: - db db: image: postgres:15 environment: POSTGRES_PASSWORD: senha123 volumes: - pgdata:/var/lib/postgresql/data volumes: pgdata:
docker compose up -d # subir tudo em background docker compose down # parar e remover tudo
FIM
Você chegou ao final.
Espero que tenha entendido como funciona.
