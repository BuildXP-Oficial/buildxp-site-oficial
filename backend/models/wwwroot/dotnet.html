01
O que é .NET?
.NET é a plataforma de desenvolvimento da Microsoft — open source, multiplataforma e gratuita. Com ela você constrói aplicações web (ASP.NET), APIs, desktop, mobile, games (Unity) e muito mais usando linguagens como C#, F# e VB.NET.
ℹ️ .NET (sem "Core") é o nome da versão moderna e unificada. A partir do .NET 5, Microsoft unificou tudo em uma única plataforma.
02
Instalar o .NET SDK
O SDK inclui tudo: runtime, CLI e ferramentas de build. Sempre instale o SDK (não só o runtime) para desenvolver.
# Windows / macOS / Linux → https://dotnet.microsoft.com/download # Baixe a versão LTS mais recente do SDK # Linux (Ubuntu/Debian via apt) sudo apt install dotnet-sdk-8.0 # macOS (via Homebrew) brew install --cask dotnet-sdk # Verificar instalação dotnet --version dotnet --list-sdks
03
Criar seu primeiro projeto
A CLI do .NET tem templates prontos para vários tipos de projeto. O comando dotnet new cria a estrutura toda para você.
# Aplicação console (ponto de partida simples) dotnet new console -n MeuApp # API Web com ASP.NET dotnet new webapi -n MinhaApi # Aplicação web MVC dotnet new mvc -n MeuSite # Biblioteca de classes dotnet new classlib -n MinhaLib # Ver todos os templates disponíveis dotnet new list
04
Estrutura de um projeto .NET
Ao criar um projeto console, você terá essa estrutura:
MeuApp/ ├── MeuApp.csproj ← configuração do projeto (como o package.json) ├── Program.cs ← ponto de entrada da aplicação └── obj/ ← arquivos de build (não commitar)
💡 Adicione bin/ e obj/ ao seu .gitignore.
05
Rodar e buildar
Os comandos mais usados no dia a dia de desenvolvimento.
cd MeuApp # Rodar o projeto (build + execução) dotnet run # Apenas compilar (sem executar) dotnet build # Build de produção (otimizado) dotnet build --configuration Release
06
Gerenciar pacotes com NuGet
NuGet é o gerenciador de pacotes do .NET — equivalente ao NPM para JavaScript. Use dotnet add package para instalar.
# Adicionar um pacote NuGet dotnet add package Newtonsoft.Json # Adicionar versão específica dotnet add package Microsoft.EntityFrameworkCore --version 8.0.0 # Remover pacote dotnet remove package Newtonsoft.Json # Restaurar todos os pacotes do projeto dotnet restore # Ver pacotes instalados dotnet list package
07
Testes com .NET
O .NET tem suporte nativo a projetos de teste. Crie um projeto de testes e rode com um comando.
# Criar projeto de testes dotnet new xunit -n MeuApp.Tests # Adicionar referência ao projeto principal dotnet add MeuApp.Tests/MeuApp.Tests.csproj reference MeuApp/MeuApp.csproj # Rodar os testes dotnet test
08
Publicar e distribuir
Gere os arquivos de publicação prontos para deploy em servidor ou container.
# Publicar para a pasta /publish dotnet publish -c Release -o ./publish # Publicar como executável único (sem precisar do .NET instalado no servidor) dotnet publish -c Release -r linux-x64 --self-contained true -o ./publish # Rodar o publicado ./publish/MeuApp
ℹ️ --self-contained gera um executável que não precisa do .NET instalado na máquina destino.
09
Primeiros passos em C#
C# é a linguagem mais comum no ecossistema .NET: sintaxe clara, forte tipagem e ótimo suporte a ferramentas. Você escreve código em arquivos .cs; num projeto console, o arquivo Program.cs costuma ser o ponto de partida. O runtime executa a partir do método Main.
💡 O terminal BuildXP tem dois treinos para .NET: comandos dotnet (CLI) e código C# — você pode usar nomes diferentes de classe e variáveis nos exercícios de código, desde que a estrutura e a lógica estejam certas.
10
Como um programa “monta”: namespace, classe e Main

namespace — agrupa nomes para não colidir com bibliotecas (como uma “pasta lógica”). Pode omitir em projetos pequenos.

class — molde de um tipo: campos, métodos e propriedades. É onde você organiza comportamento e dados.

static void Main — porta de entrada do programa. O runtime procura esse método para começar.

Console.WriteLine — imprime texto no terminal; Console.ReadLine — lê uma linha que o usuário digitou.

using System; namespace MeuNamespace { class MinhaClasse { static void Main(string[] args) { Console.WriteLine("Olá!"); } } }
11
Exemplo: área do retângulo
Variáveis guardam valores (double, int, etc.). O operador * multiplica. A interpolação $"…{variável}…" monta texto com valores dentro da string.
using System; namespace ExemploArea { class Program { static void Main(string[] args) { double largura = 4; double altura = 5; double area = largura * altura; Console.WriteLine($"Área = {area}"); } } }
12
Classes, objetos e herança (básico)

Uma classe define o “contrato” de um tipo; um objeto é uma instância criada com new. Métodos podem retornar valores com return.

Herança (class Filha : Mae) diz que a filha é um tipo especializado da mãe: reaproveita membros e pode adicionar ou substituir comportamento (override quando o método base é virtual).

using System; namespace Animais { class Animal { public virtual void Falar() => Console.WriteLine("som genérico"); } class Cachorro : Animal { public override void Falar() => Console.WriteLine("Au!"); } class Program { static void Main(string[] args) { Animal a = new Cachorro(); a.Falar(); } } }
13
Menu no terminal: visão geral

O programa mostra opções (A, B, C, S). O usuário digita uma letra; você trata no switch e repete com do … while (opcao != "S") até sair.

  1. Cartaz — Console.WriteLine descreve cada opção.
  2. ReadLine + Trim().ToUpper() — lê a escolha e compara em maiúsculas ("A", "B"…).
  3. switch — um case por opção; break; default para entrada inválida.
  4. case "C" usa chaves { } em volta do while para delimitar o int contador (escopo claro no switch).
💡 Slides 14–16: o código em três partes (didático — cada parte sozinha não precisa compilar). Slide 17: copie o programa inteiro para testar; foi conferido com dotnet build.
14
Menu — parte 1 do código

Início do arquivo até o fim do case "B": estrutura do projeto, cartaz do menu, variável opcao, laço do, leitura do usuário, abertura do switch, opções A (mensagem) e B (for 1…5).

using System; namespace BuildCSharp { class Program { static void Main(string[] args) { Console.WriteLine("4) SWITCH: Menu de comandos (A, B, C, S)"); Console.WriteLine("A - Mostrar mensagem"); Console.WriteLine("B - Contar de 1 a 5 (for)"); Console.WriteLine("C - Contagem regressiva (while)"); Console.WriteLine("S - Sair"); string opcao; do { Console.Write("\nEscolha uma opção (A/B/C/S): "); opcao = (Console.ReadLine() ?? "").Trim().ToUpper(); switch (opcao) { case "A": Console.WriteLine("Você escolheu A: Mensagem exibida com sucesso!"); break; case "B": Console.WriteLine("Você escolheu B: Contagem com FOR:"); for (int i = 1; i <= 5; i++) { Console.WriteLine($"i = {i}"); } break;
ℹ️ Para no meio do switch. Siga na parte 2 ou use só o slide 17 para colar e rodar.
15
Menu — parte 2 do código

Continuação do switch logo após o case "B": C com while regressivo (variável contador dentro de { }), S, default, fechamento do switch e condição do do … while.

case "C": { Console.WriteLine("Você escolheu C: Contagem regressiva com WHILE:"); int contador = 5; while (contador >= 1) { Console.WriteLine($"contador = {contador}"); contador--; } break; } case "S": Console.WriteLine("Saindo do menu..."); break; default: Console.WriteLine("Opção inválida. Tente novamente."); break; } } while (opcao != "S");
ℹ️ Trecho didático; sozinho não compila. Depois venha a parte 3 ou o slide 17.

Dentro do mesmo Main, depois do } while: mensagens finais e ReadKey(). Fecha método, classe e namespace.

17
Copiar e testar — programa completo

Cole no Program.cs de um projeto console (dotnet new console) e rode dotnet run. Este código foi conferido com dotnet build (0 erros e 0 avisos neste ambiente).

using System; namespace BuildCSharp { class Program { static void Main(string[] args) { Console.WriteLine("4) SWITCH: Menu de comandos (A, B, C, S)"); Console.WriteLine("A - Mostrar mensagem"); Console.WriteLine("B - Contar de 1 a 5 (for)"); Console.WriteLine("C - Contagem regressiva (while)"); Console.WriteLine("S - Sair"); string opcao; do { Console.Write("\nEscolha uma opção (A/B/C/S): "); opcao = (Console.ReadLine() ?? "").Trim().ToUpper(); switch (opcao) { case "A": Console.WriteLine("Você escolheu A: Mensagem exibida com sucesso!"); break; case "B": Console.WriteLine("Você escolheu B: Contagem com FOR:"); for (int i = 1; i <= 5; i++) { Console.WriteLine($"i = {i}"); } break; case "C": { Console.WriteLine("Você escolheu C: Contagem regressiva com WHILE:"); int contador = 5; while (contador >= 1) { Console.WriteLine($"contador = {contador}"); contador--; } break; } case "S": Console.WriteLine("Saindo do menu..."); break; default: Console.WriteLine("Opção inválida. Tente novamente."); break; } } while (opcao != "S"); Console.WriteLine("\nPrograma finalizado."); Console.WriteLine("Pressione qualquer tecla para fechar..."); Console.ReadKey(); } } }
