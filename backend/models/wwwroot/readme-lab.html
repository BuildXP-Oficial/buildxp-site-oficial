Onde pegar URLs de imagem e GIF

  • Imagens: repo GitHub (arrasta no editor do README e copia o URL), Imgur, Cloudinary, ou CDN HTTPS (ex.: skillicons.dev, shields.io, capsule-render).
  • GIFs: Giphy → Share → Copy Link (media), ou Tenor.
  • Tops / footers (TOP1–4, FOOT1–2): TOP1–3 usam capsule-render; TOP4 usa ícone + typing SVG — edita SEU_NOME, cores e as frases em lines=.
  • Usa sempre HTTPS — URLs HTTP podem ser bloqueadas.
