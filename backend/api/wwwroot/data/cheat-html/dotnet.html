INFORMAÇÕES DO SDK
dotnet --versionVer versão do .NET instalada
dotnet --list-sdksListar todos os SDKs instalados
dotnet --list-runtimesListar runtimes instalados
dotnet --infoInformações completas do ambiente
CRIAR PROJETOS
dotnet new console -n <nome>Criar aplicação console
dotnet new webapi -n <nome>Criar Web API com ASP.NET
dotnet new mvc -n <nome>Criar aplicação MVC
dotnet new classlib -n <nome>Criar biblioteca de classes
dotnet new xunit -n <nome>Criar projeto de testes xUnit
dotnet new listListar todos os templates
dotnet new sln -n <nome>Criar arquivo de solução
BUILD & EXECUÇÃO
dotnet runCompilar e executar o projeto
dotnet buildCompilar sem executar
dotnet build -c ReleaseBuild de produção otimizado
dotnet cleanLimpar artefatos de build
dotnet watch runExecutar com hot reload
PACOTES NUGET
dotnet add package <pacote>Instalar pacote NuGet
dotnet add package <pacote> --version <x>Instalar versão específica
dotnet remove package <pacote>Remover pacote
dotnet restoreRestaurar todos os pacotes
dotnet list packageListar pacotes do projeto
dotnet list package --outdatedVer pacotes desatualizados
TESTES
dotnet testRodar todos os testes
dotnet test --filter <nome>Rodar testes específicos
dotnet test --logger "console;verbosity=detailed"Testes com log detalhado
PUBLICAR & DEPLOY
dotnet publish -c Release -o ./publishPublicar para pasta
dotnet publish -r linux-x64 --self-containedPublicar executável standalone
dotnet publish -r win-x64 --self-containedExecutável standalone Windows
SOLUÇÃO & REFERÊNCIAS
dotnet sln add <projeto.csproj>Adicionar projeto à solução
dotnet sln listListar projetos da solução
dotnet add reference <projeto>Referenciar outro projeto
dotnet ef migrations add <nome>Criar migration do EF Core
dotnet ef database updateAplicar migrations ao banco
