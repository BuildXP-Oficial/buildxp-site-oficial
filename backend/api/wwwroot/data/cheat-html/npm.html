PROJETO
npm init -yInicializar projeto com padrões
npm installInstalar todas as dependências
npm ciInstalação limpa via package-lock.json
npm --versionVer versão do NPM
INSTALAR PACOTES
npm i <pacote>Instalar como dependência de produção
npm i -D <pacote>Instalar como devDependency
npm i -g <pacote>Instalar globalmente
npm i <pacote>@<versão>Instalar versão específica
npm i <pacote1> <pacote2>Instalar múltiplos pacotes
GERENCIAR PACOTES
npm uninstall <pacote>Remover pacote
npm update <pacote>Atualizar pacote específico
npm updateAtualizar todos os pacotes
npm outdatedVer pacotes desatualizados
npm listListar pacotes instalados
npm list -g --depth=0Listar pacotes globais
PRISMA (via npx)
npm i prisma -D && npm i @prisma/clientInstalar CLI (dev) e cliente no projeto
npx prisma initCriar prisma/schema.prisma e .env de exemplo
npx prisma migrate devGerar migration e aplicar no banco (dev)
npx prisma generateRegenerar Prisma Client após mudar o schema
npx prisma db pushSincronizar schema sem arquivo de migration (protótipo)
npx prisma migrate deployAplicar migrations pendentes (CI/produção)
SCRIPTS
npm startExecutar script "start"
npm testExecutar script "test"
npm run <script>Executar script customizado
npm run buildExecutar script "build"
npm run devExecutar script "dev"
AUDITORIA & SEGURANÇA
npm auditVerificar vulnerabilidades
npm audit fixCorrigir vulnerabilidades automaticamente
npm cache clean --forceLimpar cache do NPM
PUBLICAR PACOTES
npm loginAutenticar no NPM registry
npm publishPublicar pacote no registry
npm version patchIncrementar versão patch (1.0.0 → 1.0.1)
npm version minorIncrementar versão minor (1.0.0 → 1.1.0)
npm version majorIncrementar versão major (1.0.0 → 2.0.0)
