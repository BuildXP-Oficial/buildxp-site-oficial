NPM
LVL 4 · CORE

01
O que é NPM?
NPM (Node Package Manager) é o gerenciador de pacotes do Node.js. Com ele você instala, atualiza e gerencia bibliotecas e ferramentas de terceiros no seu projeto JavaScript. Pensa nele como uma "loja de peças" para seu código.
ℹ️ O NPM vem instalado automaticamente junto com o Node.js — não precisa instalar separadamente.
02
Instalar o Node.js (e NPM)
Baixe e instale o Node.js — o NPM vem junto no pacote.
# Windows / macOS → https://nodejs.org (baixe a versão LTS) # Linux (via NVM — recomendado) curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash nvm install --lts nvm use --lts # Verificar instalação node --version npm --version
03
Inicializar um projeto
O npm init cria o arquivo package.json — o coração do seu projeto, onde ficam registradas todas as dependências e scripts.
# Modo interativo (faz perguntas sobre o projeto) npm init # Modo rápido (preenche tudo com padrão) npm init -y
💡 Use npm init -y quando quiser começar rápido. Você edita o package.json depois.
04
Instalar pacotes
Existem dois tipos de dependências: as de produção (necessárias para o app rodar) e as de desenvolvimento (ferramentas usadas apenas durante o desenvolvimento).
# Dependência de produção (vai pro "dependencies") npm install express npm i express # atalho # Dependência de desenvolvimento (vai pro "devDependencies") npm install --save-dev nodemon npm i -D nodemon # atalho # Instalar versão específica npm install axios@1.6.0
ℹ️ O NPM cria a pasta node_modules — nunca a commite no Git. Adicione ao .gitignore.
05
O arquivo package.json
Entenda a estrutura básica do arquivo mais importante do seu projeto Node.js.
{ "name": "meu-projeto", "version": "1.0.0", "scripts": { "start": "node index.js", "dev": "nodemon index.js", "build": "tsc", "test": "jest" }, "dependencies": { "express": "^4.18.2" }, "devDependencies": { "nodemon": "^3.0.1" } }
06
Executar scripts
Os scripts definidos no package.json são executados com npm run.
npm run dev # roda o script "dev" npm run build # roda o script "build" npm test # atalho para "test" npm start # atalho para "start"
💡 start e test não precisam do run. Os outros precisam.
07
Restaurar dependências de um projeto existente
Quando você clona um repositório que já tem um package.json, precisa instalar as dependências antes de rodar.
# Instala tudo que está no package.json npm install # Em CI/CD — instala exatamente o que está no package-lock.json npm ci
ℹ️ Use npm ci em pipelines de deploy — é mais rápido e mais seguro que npm install.
08
.gitignore para projetos Node.js
Sempre adicione esses arquivos ao seu .gitignore.
# .gitignore node_modules/ .env dist/ build/ *.log
